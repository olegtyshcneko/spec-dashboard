## Intent

Keep the dashboard portable for readers while moving authoring and validation to a build-time compiler.

## Acceptance criteria

- [x] Produce plain HTML, CSS, JavaScript, and JSON.
- [x] Require no application server at runtime.
- [x] Generate a page for every specification and knowledge entry.
- [x] Fail before rendering when content violates the schema.

## Decisions

The project uses Astro only at build time. Generated output remains host-agnostic.
