## Intent

Give the dashboard a distinctive, highly legible identity that works offline: readable body text at a larger scale, a monospace display face for headings and data, and no runtime dependency on font CDNs.

## Acceptance criteria

- [x] Self-host Atkinson Hyperlegible Next (normal and italic variable weights) and JetBrains Mono as woff2 with their licenses committed beside them.
- [x] Load fonts from the static assets directory so built dashboards work fully offline and on any static host.
- [x] Raise the base type scale for comfortable reading and keep faint mono text at or above the recorded contrast floor.
- [x] Use the mono display face for headings, stats, and identity moments; drop redundant slug chips and add a favicon.

## Plan

1. Select legible faces and download latin variable-weight woff2 subsets with licenses.
2. Wire `@font-face` declarations into the shared stylesheet and layout head.
3. Apply the display face and revised type scale across pages, removing redundant identity elements.
4. Verify rendering across pages at desktop and mobile widths.

## Verification

- Built pages reference only local font files; no external font requests remain.
- Desktop and mobile Playwright screenshots confirmed the new faces and scale on the index, roadmap, and spec detail pages.

## Risks

- Latin-only subsets limit non-Latin content; additional subsets would need the same self-hosting treatment.
- Variable-font woff2 files add repository weight per added face.

## Out of scope

Theme switching and any further identity work beyond typography, favicon, and chip cleanup.
