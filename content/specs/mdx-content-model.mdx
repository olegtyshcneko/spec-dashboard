## Intent

Replace synchronized HTML, embedded JSON, and JavaScript manifests with one validated source document per entry.

## Acceptance criteria

- [x] Separate item kind from lifecycle state.
- [x] Assign stable `SPEC-*` and `KB-*` identifiers.
- [x] Validate categories and cross-entry references.
- [x] Support Markdown and MDX bodies.

## Out of scope

Untrusted remote content is not executed as MDX. Importers must preserve it as escaped text.
