## Principle

MDX frontmatter and body content are canonical. Generated HTML, JSON indexes, MCP resources, and diagnostics are projections of the same validated model.

## Data flow

```text
project evidence + MDX content
          ↓
 scan → validate → project graph
          ↓
 static site | CLI | MCP | CI diagnostics
```

## Boundary

The core and renderer are deterministic. Agent skills make judgment-heavy proposals, while the MCP server exposes controlled operations over the same core.
